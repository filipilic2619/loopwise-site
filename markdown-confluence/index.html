Markdown for Confluence

Write Markdown in Confluence, and move pages in and out as .md files.

Coming soon to the MarketplaceGet early access
  • Markdown macro With a side-by-side editor and live preview: GitHub-flavored tables, task lists and fenced code with highlighting.
  • Import .md files As real Confluence pages: headings, lists, tables and code blocks become native content.
  • Export any page To clean Markdown for a README or a docs repository.
  • Stores nothing Everything runs in your browser with your Confluence permissions.

Getting started

  1. Install the app from the Atlassian Marketplace (coming soon).
  2. Type /markdown in the editor to insert the macro, then write or paste Markdown.
  3. To import or export, open a page's ••• → Apps → Markdown import / export.

FAQ

Which Markdown? CommonMark with GitHub extensions: tables, task lists, strikethrough and fenced code.

What is stored? Nothing. The Markdown lives in the macro on your page.
