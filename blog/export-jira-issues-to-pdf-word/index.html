How to export Jira issues to PDF or Word (one issue or a whole list)

A customer wants a report of the open bugs, an auditor wants the change request with every comment, or a manager wants the sprint scope as a Word document. Jira Cloud has a few built-in ways to get issues out, and each has limits worth knowing before you promise a document.

Option 1: Print one issue to PDF

Open the issue, choose ••• → Print, and in the print dialog pick Save as PDF.

Good for: a quick copy of a single issue.

Watch out for: the layout follows the browser, long descriptions and tables often break across pages, and you get one issue at a time.

Option 2: The built-in Word export

On an issue, ••• → Export Word downloads a .doc file with the issue's fields and description.

Watch out for: it is an older HTML-based format, so Word may warn when opening it, formatting of tables and code blocks is basic, and sub-tasks and comments are limited.

Option 3: Export a search to CSV or Excel

Run a JQL search in Filters, then use Export to download CSV with all or the current fields. Open it in Excel or Google Sheets and format it there.

Good for: data you want to analyse.

Watch out for: it is a spreadsheet, not a document. Rich text (headings, lists, tables in the description) arrives as markup, and you have to build the report yourself every time.

Option 4: An export app

An export app turns issues into documents in one click. Issue Export for Jira (PDF & Word) is ours:

  • One issue, complete: details, the full rich-text description (headings, lists, tables, code, panels), sub-tasks and comments.
  • Any JQL as a table: choose the columns, up to 1,000 issues, landscape when there are many columns; or one page per issue.
  • PDF or real .docx that opens cleanly in Word.
  • Download or attach the file to the issue as a record.
  • Documents are made in your browser with your Jira permissions, and the app stores nothing.

Which one should you use?

  • One issue, once in a while: Print to PDF is enough.
  • Data for analysis: CSV export.
  • Documents you send to customers, auditors or managers, regularly: an export app saves the formatting work every time.
