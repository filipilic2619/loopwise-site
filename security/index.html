Security Policy

Last updated: 11 November 2026

This policy describes how Loopwise Labs (Filip Code, Serbia · MB 65422174 · PIB 111454976) protects customers who use our Atlassian Marketplace apps, and how to report a security issue.

Where our apps run

  • All our apps are built on Atlassian Forge and run entirely on Atlassian's infrastructure ("Runs on Atlassian"). We operate no servers of our own.
  • The apps make no calls to external services (no egress) and use no third-party integrations, API keys or secrets.
  • Any data an app stores (for example settings or saved plans) is kept in Atlassian Forge storage, encrypted at rest by Atlassian, and is deleted by Atlassian when the app is uninstalled.
  • Apps request only the Jira or Confluence permissions (scopes) they need. Where an app reads or changes content on a user's behalf, it does so as that user, so the product's own permissions apply.

Development practices

  • Multi-factor authentication on all accounts used to build, deploy and publish the apps (Atlassian, source control, email).
  • Workstations with full-disk encryption, automatic operating system updates, built-in malware protection and a password manager with unique passwords.
  • Dependency (SCA) scanning with npm audit and forge lint before every production deploy; we follow the OWASP Top 10.
  • We do not log credentials, tokens or unnecessary personal data. App logs stay within Atlassian.

Reporting a vulnerability

Email support@loopwiselabs.app with the app name, a description and steps to reproduce. We acknowledge reports within 2 business days. Please give us reasonable time to fix the issue before disclosing it publicly.

Fixing vulnerabilities

We triage reports using CVSS and fix confirmed vulnerabilities within the timeframes of the Atlassian Marketplace security bug-fix policy for cloud apps: Critical within 10 days, High within 4 weeks, Medium within 12 weeks and Low within 25 weeks. Fixes reach customers automatically, because the apps are hosted by Atlassian.

Security incidents

We keep a written incident response plan based on Atlassian's guidelines: detect, triage within 24 hours, contain (for example by rolling back to the last safe version), notify Atlassian and affected customers without undue delay, fix, and review. Customers are informed through Atlassian's vulnerability notification process.

Contact

Security contact: support@loopwiselabs.app.
